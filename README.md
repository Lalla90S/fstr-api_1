# FSTR API - REST API для Федерации Спортивного Туризма России

## Описание проекта

REST API для мобильного приложения спортивного туризма, разработанное для Федерации Спортивного Туризма России (ФСТР). API позволяет туристам добавлять информацию о пройденных горных перевалах через мобильное приложение.

## Функциональность

### Спринт 1
- Создание базы данных PostgreSQL для хранения данных о перевалах
- Реализация класса для работы с базой данных
- Метод POST `/submitData` для добавления новых перевалов

### Спринт 2  
- Метод GET `/submitData/{id}` для получения информации о перевале по ID
- Метод PATCH `/submitData/{id}` для редактирования перевалов со статусом 'new'
- Метод GET `/submitData/?user__email={email}` для получения всех перевалов пользователя

### Спринт 3
- Полная документация API
- Покрытие кода тестами
